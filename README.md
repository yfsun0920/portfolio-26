# portfolio-26

Personal product design portfolio, built with plain HTML, CSS, and JavaScript.

## Run locally

From this folder, start a simple local server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Stop the server with `Ctrl+C`.

## Project files

- `index.html` — portfolio homepage and content
- `styles.css` — responsive layout, typography, and project illustrations
- `script.js` — local time display and current footer year

## Publish

The repository is intended for GitHub Pages. Configure the publishing source under **Settings → Pages** after the site is ready to publish. Domain setup for `sunyifei.com` is a later step; keep any existing DNS records for email intact.
