# Yifei Sun — Portfolio

Static portfolio built with HTML, CSS, and a small JavaScript clock. The layout and content follow the existing Framer portfolio as the source reference. Images in `assets/` are copies of the images used on that public reference page.

## Preview locally

Open `index.html` in a browser, or run a simple static server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

Commit and push changes to `main` in `yfsun0920/portfolio-26`. GitHub Pages can publish the repository root. The custom domain `sunyifei.com` should be connected after the Pages URL is working.
